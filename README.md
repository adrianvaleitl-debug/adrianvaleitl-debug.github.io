# Adrian Vale — Personal Portfolio

The personal portfolio and project directory for Adrian Vale.

**Live website:** https://adrianvaleitl-debug.github.io/

This repository contains the source for the portfolio website, including its responsive editorial layout, styling, and live GitHub project feed.

## What the website includes

- Personal introduction and social links
- Featured Market Insight project
- Live public GitHub repository discovery
- Latest GitHub release tags and downloadable Windows installers / portable ZIPs when available
- Direct links to each project's website and source repository
- Clickable project cards with keyboard support
- Responsive mobile layout and reduced-motion support

The live project grid reads public repositories from the GitHub API. It excludes this portfolio repository, forks and archived repositories. Projects with Pages enabled receive an inferred website link; a repository homepage URL takes priority.

## Local preview

No build step is required.

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for Google Fonts and the live GitHub repository/release feed.

## Deployment

GitHub Actions deploys the repository to GitHub Pages whenever a commit is pushed to `main`. The workflow is in `.github/workflows/pages.yml`.
